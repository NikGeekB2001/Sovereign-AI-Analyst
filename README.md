# Sovereign-AI-Analyst

Платформа корпоративного интеллектуального анализа знаний, предназначенная для работы в полностью автономном (On-premise / Air-gapped) режиме без доступа к внешним API (OpenAI/Anthropic).

## Документация проекта

Вся проектная документация находится в директории [docs/](./docs/):

- **[docs/ADR/](./docs/ADR/)** - Архитектурные решения (ADR)
- **[docs/C4_Model/](./docs/C4_Model/)** - Диаграммы архитектуры (C4 Model)
- **[docs/Materials/](./docs/Materials/)** - Дополнительные материалы проекта

Для подробного ознакомления с документацией см. [docs/README.md](./docs/README.md).

## Особенности

- Полностью автономная работа (air-gapped)
- Поддержка русского языка
- Гибридный поиск (векторный + графовый)
- Многоагентная система (Plan-Observe-Act)
- RBAC на уровне чанков/узлов
- Локальное обслуживание моделей (vLLM)

## Архитектура

- **LLM Serving**: vLLM
- **Модели**: Qwen2.5-32B-Instruct AWQ
- **Векторная БД**: Qdrant
- **Графовая БД**: Neo4j
- **Оркестрация**: LangGraph
- **Наблюдаемость**: OpenTelemetry + Prometheus/Grafana + Langfuse
