### Краткое описание
Sovereign-AI-Analyst - это гибридная AI-система, объединяющая нейронные (векторные) и символические (графовые) методы для анализа корпоративных знаний. Система реализует GraphRAG (Graph Retrieval-Augmented Generation) архитектуру для безопасного и точного извлечения знаний из неструктурированных данных в air-gapped среде.

## Цель и задачи

### Целевое назначение
- Анализ и извлечение знаний из корпоративных документов
- Ответы на вопросы на основе внутренних знаний компании
- Поддержка принятия решений на основе анализа данных
- Обеспечение безопасности при работе с конфиденциальной информацией

### Решаемые задачи
- **Semantic Search**: Семантический поиск по документам
- **Multi-hop Reasoning**: Многопрыжковые рассуждения
- **Knowledge Graph Construction**: Построение графа знаний
- **Question Answering**: Ответы на вопросы на естественном языке
- **Information Extraction**: Извлечение сущностей и отношений

### Компоненты системы

#### 1. LangGraph Orchestrator
- **Функция**: Оркестрация компонентов, управление сессией
- **Технология**: LangGraph State Machine
- **Особенности**: Поддержка долгосрочной памяти, циклические графы

#### 2. GraphRAG Retriever
- **Функция**: Гибридный поиск (векторный + графовый)
- **Компоненты**: Vector Retriever, Graph Retriever, Reranker
- **Особенности**: RBAC на уровне результатов

#### 3. CrossEncoder Reranker
- **Функция**: Переоценка релевантности результатов
- **Модель**: CrossEncoder для reranking
- **Особенности**: Улучшенная точность результатов

#### 4. vLLM Inference Service
- **Функция**: Локальный инференс LLM
- **Модель**: Qwen 2.5/3 с квантованием
- **Особенности**: Поддержка русского языка, AWQ/GGUF

## Обучающие данные

### Источники данных
- **Корпоративные документы**: PDF, DOCX, PPTX
- **Внутренние базы знаний**: Структурированные данные
- **ERP/CRM системы**: Интеграция с корпоративными системами
- **Визуальные данные**: Сканы, чертежи (с OCR)

### Объем данных
- **Документы**: >10,000 документов
- **Векторные эмбеддинги**: >1,000,000 векторов
- **Графовые сущности**: >100,000 узлов
- **Отношения**: >500,000 ребер

### Предобработка
- **Chunking**: Разбиение документов на фрагменты
- **Embedding**: Генерация векторных эмбеддингов
- **NER**: Извлечение именованных сущностей
- **Relation Extraction**: Извлечение отношений между сущностями
