# System Prompts for LINGMA AGENT

Эта папка содержит централизованные системные промпты для всех LLM-агентов в системе.

## 📁 Структура файлов

- `system_prompts.py` — Основные системные промпты для всех агентов
- `__init__.py` — Экспорт промптов для удобного импорта

## 🎯 Доступные промпты

### 1. PLANNER_PROMPT
**Назначение:** Декомпозиция сложных запросов пользователя на последовательность шагов  
**Используется в:** `planner_node`  
**Модель:** Qwen 2.5-14B-Instruct  
**Формат ответа:** JSON список шагов

### 2. GRAPH_QUERY_PLANNER_PROMPT
**Назначение:** Генерация Cypher-запросов для Neo4j  
**Используется в:** `graph_query_planner_node`  
**Модель:** Qwen 2.5-7B-Instruct  
**Формат ответа:** Чистый Cypher код

### 3. SYNTHESIZER_PROMPT
**Назначение:** Сборка финального ответа для пользователя  
**Используется в:** `synthesize_node`  
**Модель:** Qwen 2.5-7B-Instruct  
**Особенности:** Учитывает RBAC политики, отвечает на русском языке

### 4. JUDGE_SAFETY_PROMPT
**Назначение:** Оценка безопасности ответа (PII detection, prompt injection)  
**Используется в:** Output Guardrails  
**Модель:** Saiga-7B  
**Формат ответа:** 'SAFE' или 'UNSAFE'

### 5. JUDGE_QUALITY_PROMPT
**Назначение:** Оценка качества ответа (релевантность, логика, галлюцинации)  
**Используется в:** Post-response evaluation  
**Модель:** Saiga-7B  
**Формат ответа:** JSON с оценками 1-5

## 📝 best practices

1. **Централизация:** Все промпты хранятся в одном месте для легкого управления
2. **Версионирование:** При изменении промпта обновляйте документацию
3. **Тестирование:** Каждый промпт должен быть протестирован с разными входными данными
4. **Безопасность:** Не храните чувствительные данные в промптах

## 🔄 Обновление промптов

При изменении промпта:
1. Обновите текст в `system_prompts.py`
2. Протестируйте с различными запросами
3. Обновите документацию (если изменилась логика)
4. Закоммитьте изменения с понятным commit message
